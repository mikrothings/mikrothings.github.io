Mikrothings organizasyonunun GitHub Pages kök sitesi: https://mikrothings.github.io/

`googled8355b09dda91c2a.html` dosyasını **silmeyin**: Google, Claude Transfer'in OAuth uygulamasının ana sayfasının bize ait olduğunu bu dosyayla doğrular.

Org'daki başka bir repo Pages ile yayınlandığında `https://mikrothings.github.io/<repo-adı>/` altında görünür; örneğin [claudetransfer-site](https://github.com/mikrothings/claudetransfer-site) → https://mikrothings.github.io/claudetransfer-site/. Yeni bir proje eklenince `index.html`'deki proje listesine bir kart ekleyin.

Sayfa düz HTML'dir, derleme adımı yoktur. `main` dalına yapılan her push birkaç dakika içinde yayına çıkar.
